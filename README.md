# Talent Lab

ქართული სასწავლო სივრცე HR-ის საფუძვლებისა და ტექნიკური რეკრუტინგისთვის.

## შესაძლებლობები

- HR და ტექნიკური რეკრუტინგის გაკვეთილები და ცოდნის ტესტები
- HR & Tech ლექსიკონი, თემატური ფილტრები და ძიება
- ინტერვიუს სტუდია და ტექნიკური კონცეპტების ტესტები
- Sourcing Lab, რესურსების ბიბლიოთეკა და პირადი ჩანაწერები

## GitHub-ზე ატვირთვა

1. ZIP ფაილი ჩამოტვირთე და გახსენი Windows-ის **Extract All** ბრძანებით.
2. გახსენი https://github.com/Mari-4m/talent-lab.
3. აირჩიე **Add file → Upload files**.
4. ატვირთე ამ საქაღალდის ფაილები პირდაპირ რეპოზიტორიის მთავარ დონეზე. ZIP არქივი ან გარე საქაღალდე არ ატვირთო.
5. ცვლილების აღწერად ჩაწერე **Add Talent Lab website** და დააჭირე **Commit changes**.

## GitHub Pages

რეპოზიტორიაში გახსენი **Settings → Pages**:

- Source: **Deploy from a branch**
- Branch: **main** (ან ის განშტოება, სადაც ფაილები ატვირთე)
- Folder: **/(root)**
- დააჭირე **Save**.

გამოქვეყნების სტატუსი ნახე **Actions** ჩანართში. წარმატების შემდეგ საიტის ზუსტი ბმული Pages გვერდზე გამოჩნდება. სტანდარტული მისამართია https://mari-4m.github.io/talent-lab/.

## ადგილობრივი შემოწმება

შეგიძლია ბრაუზერში გახსნა `index.html`. უფრო სრული ტესტირებისთვის, თუ Python გაქვს, ამ საქაღალდეში გაუშვი `python -m http.server 8000`, შემდეგ გახსენი http://localhost:8000.

ინსტალაცია და build ნაბიჯი საჭირო არ არის: საიტი იყენებს HTML, CSS და JavaScript ფაილებს. რესურსების ფარდობითი ბმულები თავსებადია GitHub Pages-ის პროექტის ქვეგზასთან.

## მონაცემები და ავტორიზაცია

მიმდინარე ვერსიაში მომხმარებლის პროგრესი, ჩანაწერები და სანიშნეები ბრაუზერში ინახება. სხვა დომენზე გადასვლისას ძველი ბრაუზერული მონაცემი ავტომატურად არ გადადის. გადასვლამდე შეგიძლია არსებული საიტიდან პირადი ანგარიში ჩამოტვირთო.

რეგისტრაცია, ანგარიშზე შესვლა და მოწყობილობებს შორის სინქრონიზაცია ამ ვერსიაში დამატებული არ არის. ასეთი შესაძლებლობებისთვის საჭიროა შესაბამისი ავტორიზაციისა და მონაცემების სერვისის ინტეგრაცია.

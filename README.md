## მონაცემები

სტუმრის პროგრესი ამ ბრაუზერში ინახება. Google-ით შესვლის შემდეგ გაკვეთილები,
ჩანაწერები, სანიშნეები, საკუთარი რესურსები და პრაქტიკის ისტორია Supabase-ში
ამ მომხმარებლის ჩანაწერში ინახება. RLS მომხმარებელს მხოლოდ საკუთარი
ჩანაწერის წაკითხვისა და ცვლილების უფლებას აძლევს.
ინტერნეტის დაკარგვისას ცვლილებები რჩება ამ ბრაუზერში და კავშირის აღდგენისას
სინქრონიზდება. გასვლამდე საჭიროა შენახვა; ↓ ღილაკი JSON ასლს ჩამოტვირთავს.

საიტში მხოლოდ საჯარო `sb_publishable_` გასაღებია. Client Secret, მონაცემთა
ბაზის პაროლი და `sb_secret_`/service_role კოდში ან GitHub-ზე არ ატვირთო.
Google-ით შესვლა ითხოვს მხოლოდ openid, email და profile უფლებებს.
Gmail-ისა და Drive-ის მონაცემებზე წვდომა არ არის მოთხოვნილი.

არსებული ანალიტიკა, შეფასებები და ადმინის სივრცე ძველ სერვისთან მუშაობს.
GitHub Pages სერვერს არ უშვებს; `backend/` მხოლოდ არსებული სერვისის წყაროა.
ამ ცვლილებით ადმინის ავტორიზაცია არ იცვლება.
